1. التنقل وعرض وتعديل الملفات

pwd مسار العمل

عرض مسار المجلد الحالي الذي تقف عليه (Print Working Directory).

ls -la عرض التفاصيل

عرض كافة الملفات والمجلدات بما فيها المخفية مع الصلاحيات وتاريخ التعديل.

cd [directory] تغيير المجلد

الانتقال بين المجلدات (`cd ..` للرجوع خطوة، `cd ~` للمجلد الرئيسي).

touch [filename] إنشاء ملف

إنشاء ملف فارغ جديد بدون محتوى (مثال: `touch new.txt`).

nano [filename] محرر النصوص

فتح ملف وكتابة/تعديل المحتوى داخله. اضغط `Ctrl + X` للحفظ والخروج.

cat / tac قراءة الملفات

`cat` يعرض المحتوى من البداية، بينما `tac` يعرضه بشكل معكوس (من السطر الأخير للأول).

2. الصلاحيات وإدارة الأذونات (Chmod & Umask)

القيمة الرقمية الرمز (Symbol) نوع الصلاحية
4rقراءة (Read)
2wكتابة (Write)
1xتنفيذ (Execute)
0-حجب/بدون صلاحية

كيف تترجم الأرقام الثلاثة في chmod 755؟

  • الرقم الأول (7): للمالك (Owner) = 4 + 2 + 1 = rwx
  • الرقم الثاني (5): للمجموعة (Group) = 4 + 0 + 1 = r-x
  • الرقم الثالث (5): لبقية المستخدمين (Others) = 4 + 0 + 1 = r-x

3. إدارة الحسابات والملكية

sudo adduser [name] إضافة مستخدم

إضافة حساب مستخدم جديد للنظام، وسيطلب تحديد كلمة مرور له.

sudo chown [user] [file] تغيير الملكية

تحويل ملكية الملف من المستخدم الحالي إلى مستخدم آخر.
